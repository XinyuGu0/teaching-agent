# PPT生成系统架构设计

## 问题分析

### 旧架构的问题
1. **过度依赖LLM一次性生成**：让GLM一次性生成完整的PPT JSON，输出不稳定
2. **质量难以保证**：页数、内容质量、图片质量都依赖LLM的"自觉性"
3. **缺乏验证机制**：生成后没有质量检查和修正
4. **图片搜索不可靠**：依赖LLM返回图片URL，经常返回无效链接

### 根本原因
- 将复杂的设计任务完全交给LLM
- 没有结构化的生成流程
- 缺少模板化和标准化

## 新架构设计

### 核心思想：分层生成 + 模板化设计 + 质量验证

```
用户需求
    ↓
需求提取（智能关键词匹配）
    ↓
大纲生成（LLM生成结构）
    ↓
【结构化生成器】
    ├─ 1. 模板选择（根据风格选择配色和布局）
    ├─ 2. 逐页内容生成（LLM只生成文本内容）
    ├─ 3. 模板应用（使用预定义布局）
    ├─ 4. 图片添加（独立的图片搜索）
    └─ 5. 质量验证（检查页数、边界、内容）
    ↓
完整PPT
```

## 模块说明

### 1. PPT模板系统 (`ppt_templates.py`)

**职责**：提供标准化的幻灯片布局模板

**核心功能**：
- `get_title_slide()`: 标题页模板
- `get_content_slide()`: 内容页模板（左文右图）
- `get_full_content_slide()`: 全宽内容页模板
- `get_two_column_slide()`: 双栏内容页模板
- `add_image_to_slide()`: 向幻灯片添加图片
- `get_color_scheme()`: 根据风格获取配色方案

**优势**：
- 布局标准化，确保视觉一致性
- 配色专业化，预定义多种风格
- 位置精确化，避免元素重叠或超出边界

### 2. 结构化PPT生成器 (`structured_ppt_generator.py`)

**职责**：协调整个PPT生成流程

**生成流程**：
```python
1. 生成标题页
   - 使用模板
   - 应用配色方案

2. 逐页生成内容
   for each slide in outline:
       - 调用LLM生成详细内容（只生成文本）
       - 使用模板创建幻灯片
       - 应用配色方案

3. 添加图片
   for each content slide:
       - 搜索相关图片
       - 使用模板添加到固定位置

4. 质量验证
   - 检查页数是否正确
   - 检查元素是否超出边界
   - 检查内容是否完整
```

**关键方法**：
- `generate_ppt()`: 主生成流程
- `_generate_detailed_content()`: 为单页生成详细内容
- `_search_quality_image()`: 搜索高质量图片
- `validate_ppt_quality()`: 验证PPT质量

### 3. 需求提取改进 (`conversation_state_machine.py`)

**改进点**：
- 使用正则表达式匹配页数（支持"12页"、"12张"等多种表达）
- 关键词匹配提取受众、用途、风格
- 不依赖严格的顺序提取

### 4. 大纲生成改进 (`glm_service.py`)

**改进点**：
- 强制要求生成指定页数
- 在提示词中多次强调页数要求
- 增加页数验证和警告
- 提高max_tokens支持更多页数

## 新旧对比

| 维度 | 旧架构 | 新架构 |
|------|--------|--------|
| **生成方式** | LLM一次性生成完整JSON | 分步骤生成，模板化组装 |
| **页数控制** | 依赖LLM遵守指令 | 严格按大纲页数生成 |
| **布局设计** | LLM自由发挥 | 预定义模板，标准化布局 |
| **配色方案** | LLM随机选择 | 根据风格预定义配色 |
| **内容生成** | 一次性生成所有内容 | 逐页生成，独立验证 |
| **图片处理** | LLM搜索返回URL | 独立搜索，固定位置 |
| **质量保证** | 无验证机制 | 多层验证（页数、边界、内容）|
| **可维护性** | 难以调试和优化 | 模块化，易于扩展 |

## 优势

### 1. 可靠性提升
- **页数保证**：严格按大纲生成，不会多也不会少
- **布局稳定**：使用预定义模板，不会出现元素重叠或超界
- **配色专业**：预定义配色方案，视觉效果一致

### 2. 质量提升
- **内容深度**：逐页生成，每页都有质量验证
- **视觉效果**：专业的模板和配色
- **图片相关性**：独立搜索，更精准

### 3. 可扩展性
- **新增模板**：轻松添加新的布局模板
- **新增风格**：只需添加配色方案
- **自定义验证**：可以添加更多质量检查规则

### 4. 可维护性
- **模块化设计**：各模块职责清晰
- **易于调试**：可以单独测试每个步骤
- **易于优化**：可以针对性优化某个环节

## 总结

新架构通过**分层生成 + 模板化设计 + 质量验证**的方式，从根本上解决了旧架构的问题：

1. **不再依赖LLM的"自觉性"**：使用模板和验证机制确保质量
2. **页数精确控制**：严格按大纲生成，不会出错
3. **视觉效果专业**：预定义配色和布局
4. **内容质量可控**：逐页生成和验证
5. **易于维护和扩展**：模块化设计

这是一个**工程化的解决方案**，而不是简单的提示词优化。
