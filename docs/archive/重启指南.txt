=========================================
模板上传功能修复 - 后端重启指南
=========================================

【重要】必须重启后端服务才能使配置生效！

步骤1: 停止后端
- 在运行后端的终端窗口中按 Ctrl+C

步骤2: 重新启动后端
```bash
cd backend
python run.py
```

步骤3: 等待后端启动完成
- 看到 "Running on http://127.0.0.1:5000" 表示启动成功

步骤4: 刷新浏览器
- 按 Ctrl+F5 (Windows) 或 Cmd+Shift+R (Mac) 强制刷新
- 如果还不行，清除浏览器缓存

步骤5: 测试上传
1. 访问 http://localhost:5173
2. 登录系统
3. 点击"模板管理"
4. 点击"上传模板"
5. 选择PPT文件并上传

=========================================
如果重启后仍有问题，请提供：
1. 后端终端的完整日志
2. 浏览器控制台的错误信息
=========================================
